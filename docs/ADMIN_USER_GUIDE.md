# Admin User Guide (Reception & Staff)

Written for daily gym operation. The app works on your phone, a tablet or
the reception computer — install it from the browser menu ("Add to Home
screen") so it opens like an app. Switch between English and తెలుగు with
the button in the top bar; your choice is remembered on that device.

## Signing in

Open the admin address your owner gave you → enter your email and password.
Too many wrong attempts locks sign-in for 15 minutes. If you forget your
password, the owner can set a new one for you.

## The dashboard = your morning to-do

Big cards on top answer "what needs attention": active members, expiring in
7 days, recently expired, today's and this month's collections, today's
check-ins, leads to follow up. Below: the **expiry queue** — each person has
**Call**, **WhatsApp** (opens WhatsApp with the renewal message already
written, in the member's language) and **Renew** buttons.

## New member (under 2 minutes)

1. **New member** → type the mobile number → Next.
   - If the number already exists you'll see the member — open them
     instead of creating a duplicate.
2. Fill name (only first name is required), branch and anything else you
   know. → Next.
3. Choose the plan (prices shown), start date (today is pre-filled), promo
   code if any, tick joining fee if it applies.
4. Enter the amount received and payment method (UPI reference for UPI).
5. Confirm — the membership is active, the receipt is created, and you're
   on the member's page. Open the receipt to print or share it.

## Find member / member page

**Members** → type name, mobile or member number. The member page shows
plan, expiry, days remaining and buttons for **Check in · Renew · Payment ·
WhatsApp**, plus history tabs (memberships, payments, attendance, PT).

## Renewals

Member page → **Renew**. Every plan shows the exact new period (e.g.
"01-Dec-2026 → 28-Feb-2027") before you confirm. Add a promo code and the
payment in the same step. Renewing early never loses days — the new period
starts the day after the current expiry.

## Payments & receipts

Member page → **Payment** for any amount (e.g. clearing dues). Every payment
gets a numbered receipt automatically — numbers can never repeat or be
edited. Mistakes are corrected with a **refund** (accountant/owner only),
which keeps the original record intact.

## Check-in

**Attendance** → search the member (or type/scan their app QR). You'll see
their photo/name/plan/expiry with a clear go/no-go. Expired or frozen
members show a warning — you can still allow entry ("Allow entry anyway"),
which is recorded. Double taps within 10 minutes are ignored.

## Freeze (manager)

Member page → **Freeze** with dates and a reason. When the member returns,
**Unfreeze** — the expiry moves forward by exactly the days frozen (if the
freeze was set to extend). Everything is logged.

## Leads

**Leads** → add walk-ins/phone enquiries in seconds with a follow-up date.
Use WA/Call from the list; when they join, **Convert** carries their name
and number straight into new-member onboarding.

## What the buttons you don't see mean

If you can't see Refund, Settings, Audit or Freeze — your role doesn't
include them. Ask the owner if you need access; nothing is hidden behind
tricks, permissions are real.
